## Contributing
1. Fork the [development](https://github.com/CodeByCon/Lazyman-Suite/tree/development) branch and open a pull request. All PRs are reviewed before merging.
2. After a few merged contributions you may be invited as a collaborator.
3. Ensure code quality and avoid heavy library usage.
4. Correctly reference any code in relevant issues opened.
5. AI-assisted PRs are welcome if you disclose it, understand and
have tested what you're submitting, and can explain it in review. Low-effort
or untested AI submissions will be closed. AI is a tool not a "do-it" button.
